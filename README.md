# Azadi Jewellery — Digital Showroom Concept

An independent React concept for Kazem Azadi Jewellery Trading LLC, designed to demonstrate a more personal, editorial digital customer experience for a Sales Officer application.

Collection names and product photography are illustrative, not verified company inventory.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Stack: React, Vite, Lucide icons, responsive CSS, and original WebP campaign imagery.
