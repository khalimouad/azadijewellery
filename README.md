# Azadi Jewellery — Digital Showroom Concept

An independent React concept for Kazem Azadi Jewellery Trading LLC, designed to demonstrate a more personal, editorial digital customer experience for a Sales Officer application.

The concept combines a custom monogram, original campaign-style imagery, an interactive collection edit, a shortlist interaction, a responsive menu, and clear showroom visit actions. Collection names and product photography are illustrative; they are not presented as verified company inventory. The page is a candidate-created concept, not the company's official website.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Stack

- React + Vite
- Lucide icons
- Responsive CSS with reduced-motion support
- Original WebP campaign imagery in `public/images`

## Preview

The concept is designed for desktop and mobile. Collection filters, shortlist buttons, the product detail dialog, and mobile navigation are interactive.
